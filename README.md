# Task 16: Load a CSV Dataset

## Introduction
This project demonstrates how to load a CSV dataset using Python's Pandas library and display the first five and last five records.

## Objective
To understand how to import a CSV file into a Pandas DataFrame and inspect its contents.

## Tools and Technologies
- Python
- Pandas
- Jupyter Notebook
- CSV Dataset

## Dataset
The Iris dataset contains 150 records and 5 columns:
- `sepal_length`
- `sepal_width`
- `petal_length`
- `petal_width`
- `species`

## Implementation
The program uses `pd.read_csv()` to load the dataset, `df.head()` to display the first five records, and `df.tail()` to display the last five records.

It also displays the dataset shape and column names.

## Results
- Successfully loaded the Iris CSV dataset.
- Displayed the first five records.
- Displayed the last five records.
- Verified that the dataset contains 150 rows and 5 columns.

## Conclusion
This task provided practical experience in loading CSV files with Pandas and inspecting tabular data, which is an important first step in data analysis and machine learning workflows.
